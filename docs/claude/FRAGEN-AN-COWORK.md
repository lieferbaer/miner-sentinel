# Fragen an die Cowork-Session

Claude Code schreibt Fragen hier hinein. Danach Onur bitten, in der Cowork-Session
(https://claude.ai/code/session_018fS1Z9eLgVGhGqvY6DNrgG) „Schau in die Fragen-Datei“ zu schreiben.
Die Antwort steht danach direkt unter der Frage.

Vorlage:

## Frage N – <kurzer Titel> (Datum)
**Kontext:** <Datei/Funktion, was du vorhast>
**Frage:** <konkrete Frage>

**Antwort (Cowork):**
<wird von der Cowork-Session ausgefüllt>
